# 📄 Resume Analyser

> An intelligent tool that parses, structures and scores resumes to speed up screening.

## 📌 Problem
Screening resumes manually is repetitive and inconsistent — recruiters waste hours reading the same format over and over.

## 💡 Solution
A tool that reads resume content, extracts key information (skills, experience, education) and produces a structured analysis.

## ⚙️ Tech Stack
- **Language:** Python
- **Concepts:** Text Parsing, Data Extraction, Scoring Logic

## 🧠 Key Learnings
- Text processing and parsing unstructured data
- Designing scoring logic from extracted signals
- Turning messy input into structured output

## 🔧 How to Run
```bash
git clone https://github.com/sourya2580/resume-analyser
cd resume-analyser
pip install -r requirements.txt
python analyse.py
```
